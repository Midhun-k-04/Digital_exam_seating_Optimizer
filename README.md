# Digital Exam Seating Optimizer

## Project Overview

The Digital Exam Seating Optimizer is a Java-based application designed to organize student seating arrangements for examinations. It uses a greedy allocation approach to assign seats and aims to make the seating process more organized and efficient.

## Technologies Used

- **Programming Language:** Java
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **User Interface:** Java Swing
- **Data Structures:** Linked List
- **Algorithm:** Greedy Allocation

## Features

- Student data management
- Exam seat allocation
- Database connectivity using JDBC
- Graphical user interface
- Organized seating allocation using a greedy algorithm

## Project Structure

- `src/` — Java source code
- `lib/` — Required library files
- `.gitignore` — Specifies files Git should ignore

## Requirements

- Java Development Kit (JDK)
- MySQL Server
- MySQL Connector/J
- Java-compatible IDE, such as VS Code

## Setup and Execution

1. Clone or download this repository.
2. Configure the MySQL database according to the application's database requirements.
3. Update the database connection settings in the relevant Java file.
4. Ensure the MySQL Connector/J library is available on the classpath.
5. Compile and run the application's main class.
